# M1.6 — BotAI status in BotWeb

BotWeb supports the optional PBMP/1 capability `botai.status`.

A bot that advertises the capability gets a BotAI navigation entry and a
read-only operational status page. Bots that do not advertise it are unchanged.

The frontend is implementation-neutral: there is no Engo-specific branch.
LuCa, AmBot or another PBMP implementation can use the same view by advertising
and implementing `botai.status`.

BotWeb only renders the privacy-safe metadata supplied by the bot. BotWeb does
not connect to BotAI directly and is not in the bot-to-BotAI data path.
Conversation content, prompts, credentials and BotAI endpoint URLs are not
required or requested.
